# E-library SPA

Lightweight single-page E-library built with HTML, CSS, and vanilla JavaScript. Data is stored in the browser via LocalStorage so no server setup is required.

How to run

1. Open `spa/index.html` in a browser (double-click or use `File > Open`).
2. Use Add Book to create entries. Use Export/Import to move data between machines.

Notes

- Works offline in modern browsers.
- For a server-backed version, I can connect this to a simple Node/Express or Java backend.
